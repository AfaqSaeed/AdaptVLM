# Reports

The maintained [research report](research-report.md) and compact
[software-validation evidence](evidence/phase6-evidence.json) are intended for version control.
The evidence preserves measured values and hashes without redistributing model checkpoints.

Generated raw evaluation JSON, benchmark runs, JUnit XML, plots and worker logs are ignored.
Keep these locally when reproducing a run. New evidence belongs in a separate file; changing
timings must not silently replace a historical observation. These fixture results are software
validation only, not evidence of research effectiveness.
